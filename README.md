# Солнечный год

Ритм природы, собственный выбор и память о прожитом.

Сайт-презентация v2, рабочий веб-календарь и бесплатный подписанный Android APK.
Веб-приложение открывается в браузере, полный ZIP также работает локально через index.html.

## Статус

Пробная сборка1.0.0 /10018, не финальный production-релиз. Проверки браузерной версии
и целостности файлов выполнены. Полная приёмка этого APK на физических телефонах
ещё не завершена. Важные уведомления пока дублируйте привычным способом.

В составе: солнечный календарь с сохранённым летоисчислением, обычное и расчётное
солнечное время, Солнце/Луна, погода и ветер по явному обновлению, заметки,
напоминания, месячный путь Выбории и персонализация названий, локальный backup.
Без рекламы, подписок и платных функций. Google Play не требуется.

## Что хранится здесь

`public/` содержит только публикуемые файлы. Это экспорт действующего приложения,
не новый календарный проект. APK подписан; закрытого ключа подписи здесь нет.
Исходный Android-проект, внутренние отчёты, Obsidian, доноры и личные данные не
являются частью этого репозитория. Авторское обращение: ALEX_DOC.

## Проверка и размещение

Технический адрес Cloudflare: https://solar-year.pages.dev/
Веб-приложение: https://solar-year.pages.dev/app/
Репозиторий публикации: https://github.com/infob2bcai-png/solar-year
Владелец выбрал новый адрес с названием Solar-Year; используется этот адрес pages.dev.
Репозиторий закрытый, сайт и загрузки открыты по ссылке. Для скачивания с сайта
учётная запись GitHub не нужна.

Требуется Node.js22+. `npm test` проверяет файлы и закрытую информацию перед отправкой.
`npm run deploy` загружает только public/ в Cloudflare Pages через Wrangler.
Cloudflare авторизация нужна только в среде оператора; не записывайте токены в файлы.
Автоматического деплоя из GitHub пока нет, секрет Cloudflare в GitHub не переносился.
Не заменяйте APK под тем же номером: новой версии нужен новый файл и своя проверка.

Сайт использует статическую раздачу без Worker, базы пользователей, API исследования
или платной активации. Личные данные остаются в браузере/телефоне; между устройствами
нет автоматической синхронизации. Перед обновлением, сменой браузера или адреса
сайта экспортируйте резервную копию. JSON backup не зашифрован.
