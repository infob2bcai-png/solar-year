«Солнечный год» бесплатный и планируется к прямому распространению APK через рекомендации пользователей, без Google Play. Это не отменяет правил разрешений, прозрачности передачи данных, отказа от исследования и удаления. Участие в исследовании не является платой за использование или условием доступа к приложению.

Телефон, адрес и другие личные данные в приложение не добавляются.

Текущая версия приложения выполняет астрономические расчеты локально. Личные заметки, напоминания, режим дня и сохраненные места сохраняются в локальном хранилище устройства.

Погода и прогноз обновляются только по явному нажатию пользователя и только при сохраненной ручной или активной локации. Для запроса погоды приложение отправляет координаты в Open-Meteo Forecast API и сохраняет последний ответ в локальный offline cache. Фонового автообновления погоды в этой версии нет.

На экране ветра можно открыть текущую локацию и два избранных места из списка до пяти. Переключение вкладки читает локальный кэш без сетевого запроса. Кнопка обновления запрашивает выбранное место, «Обновить все» отправляет координаты трёх открытых мест, а не всего списка избранного. Для каждого места отдельно сохраняются прогноз и часовой пояс. Выбор вкладки не меняет активную локацию календаря и не создаёт запись маркетингового исследования.

Геолокация телефона запрашивается только по нажатию кнопки GPS, через системное разрешение Android. Фонового отслеживания нет. Координаты можно заменить вручную или выбрать город. Поиск города отправляет введённое название и язык в Open-Meteo Geocoding API. Часовой пояс определяется по координатам локально либо приходит с результатом поиска; пользователь может выбрать другой пояс вручную. Возле границ зон автоматическое определение может быть приблизительным.

## Добровольное исследование

В настройках предлагается участие в маркетинговом исследовании. Вариант участия предварительно выбран, но запись создаётся только после явного подтверждения. Отказ не ограничивает календарь, погоду или GPS.

Состав локальной записи: приблизительная область на сетке 0,5 градуса, часовой пояс, RU/EN, версия приложения, Android/web, дата и случайный идентификатор участника. Точные GPS-координаты, название сохранённого места, имя, контакты, заметки и напоминания в неё не входят. Это псевдонимизированная запись, не обещание полной анонимности.

Сохраняется только последняя запись; при следующем запуске запись старше 30 дней удаляется. Отказ или удаление данных сразу удаляет запись и идентификатор из хранилища приложения. Согласие/отказ хранится отдельно. Исследование не включается в экспорт личного backup.

API исследования пока не настроен, сетевой отправки этой записи нет. Перед подключением получателя потребуется отдельное подтверждение с указанием получателя, целей, состава данных и правил удаления. Локальный Operator Center сейчас читает только технический отчёт проекта (APK и проверки), а не данные телефонов.

Ветровые значения в этой версии производятся из того же погодного ответа Open-Meteo и не используют отдельный сетевой сервис. Станционные и картографические источники в этой архитектурной стадии еще не подключены как пользовательские сетевые сервисы.

## Резервные копии

Экспорт backup создает JSON-снимок настроек, заметок, напоминаний, режима дня, сохраненных мест и погодного кэша. Файл не зашифрован и может содержать точные координаты и личные записи: храните его в доверенном месте. Исследовательская запись и идентификатор участника не экспортируются.

На Android место сохранения и открытия файла выбирается через системный диалог. Приложение не получает общий доступ к файлам. Если в диалоге выбран облачный провайдер, файл передается ему по вашему выбору, а не автоматически приложением. Экспортированный файл остается вне хранилища приложения и не удаляется при его удалении.

Открытие файла только загружает его в форму; данные заменяются после отдельной команды импорта. Перед записью проверяются формат, размер (до 16 МиБ) и содержимое. При ошибке записи выполняется восстановление прежних данных; прерванный импорт восстанавливается при следующем запуске. Нечитаемое локальное хранилище не сбрасывается молча.

В Android-манифесте отключено системное резервирование; правила исключают данные приложения из облачного backup и переноса устройства. Фактическое поведение конкретного производителя отдельно проверяется на физических телефонах. Для смены устройства и перехода с debug на release используется явный экспорт/импорт. Обычное обновление APK с той же подписью сохраняет локальные данные.

## Персонализация месяцев

Просмотры подробностей Выбории, личные имена месяцев, история имён и дополнительные SVG-иконки хранятся только на устройстве. Тексты заметок остаются в общем локальном блокноте; для пути месяца используется только их привязка и наличие собственного текста. Эти данные не передаются в маркетинговое исследование или на сервер.

SVG выбирается явно из локального файла, до 32 КиБ. Скрипты, внешние ссылки и встроенные растровые изображения не допускаются. Отключение Выбории не удаляет заметки, имена и уже открытые права. Backup формата 0.2.0 включает этот слой. При восстановлении сохраняются ранее открытые права, а имена и пути берутся из выбранной новой копии; копия 0.1.0 без персонализации не заменяет этот слой. Экспортируемый JSON содержит личные данные, его следует передавать только доверенным получателям.
